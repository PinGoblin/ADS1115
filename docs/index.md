# PinGoblin ADS1115

The PinGoblin ADS1115 adds four 16-bit analogue inputs to a Raspberry Pi, ESP32 or any other I²C host. Each channel has its own 3-pin sensor header, a protected input and a solder jumper that sets it up for bare resistive sensors.
