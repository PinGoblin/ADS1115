    Raspberry Pi package: pingoblin_ads1115¶

    Raspberry Pi library for the PinGoblin ADS1115 4-channel 16-bit ADC board.

    Talks to the ADS1115 directly with smbus2, and has the same methods as the MicroPython ads1115 module. It also works with any other ADS1115 breakout.

    Install on the Pi, in a virtual environment:

    pip install "git+https://github.com/PinGoblin/ADS1115#subdirectory=python"
    Name Purpose
    ADS1115 One board: single-ended and differential reads, range, data rate, RDY pin
    find_boards() Finds every board on the bus (0x48–0x4B)
    resistance_from_voltage() Resistive sensor resistance with the RES jumper closed
    ntc_celsius() Thermistor temperature (Beta equation)
    percent_of_range() Voltage as a percentage of a range
    load_calibration(), apply_calibration(), save_calibration() Per-channel gain correction

    ADDRESSES module-attribute ¶

    ADDRESSES = (72, 73, 74, 75)

    Valid I²C addresses: 0x48 (JP1, default), 0x49 (JP2), 0x4A (JP3) and 0x4B (JP4).

    ADDRESS_JUMPERS module-attribute ¶

    ADDRESS_JUMPERS = {
    "JP1 (default)": 72,
    "JP2": 73,
    "JP3": 74,
    "JP4": 75,
}

    I²C address selected by each address jumper. Exactly one jumper must be closed.

    CAL_FILE module-attribute ¶

    CAL_FILE = 'calibration.json'

    Default calibration file, calibration.json in the current working directory. Written by 06_calibrate.py.

    R_EXCITATION module-attribute ¶

    R_EXCITATION = 10000.0

    Excitation resistor R5–R8 (Ω), connected from VDD to SIG when a channel's RES jumper is closed.

    R_SERIES module-attribute ¶

    R_SERIES = 4700.0

    Series protection resistor R1–R4 (Ω) between each SIG pin and the ADC input. For reference only.

    VDD_NOMINAL module-attribute ¶

    VDD_NOMINAL = 3.3

    Assumed supply voltage (V). Measure the real VDD at TP5–TP6 and set this for accurate resistive readings.

    ADS1115 ¶

    ADS1115(
    bus: int | object = 1,
    address: int = 72,
    fsr: float = 4.096,
    rate: int = 128,
)

    One ADS1115 board on an I²C bus.

    Example 
    from pingoblin_ads1115 import ADS1115

with ADS1115(address=0x48) as adc:   # I²C bus 1, ±4.096 V, 128 samples/s
    print(adc.read_voltage(0))       # CH0 (header J2), volts

    Parameters:

    Name Type Description Default
    bus int | object

    I²C bus number (1 on a Raspberry Pi), or an open bus object with write_i2c_block_data() and read_i2c_block_data(), such as smbus2.SMBus.

    		 1
    address int

    I²C address set by the address jumpers: 0x48 (default), 0x49, 0x4A or 0x4B.

    		 72
    fsr float

    Full-scale range (±V): 6.144, 4.096, 2.048, 1.024, 0.512 or 0.256. Use 4.096 on a 3.3 V board.

    		 4.096
    rate int

    Samples per second: 8, 16, 32, 64, 128, 250, 475 or 860. Slower rates give lower noise.

    		 128

    Raises:

    Type Description
    ValueError

    If address, fsr or rate is not one of the allowed values.
    OSError

    If the I²C bus cannot be opened.

    Attributes:

    Name Type Description
    address int

    The board's I²C address.
    fsr float

    Full-scale range (±V). Can be changed between reads.
    rate int

    Samples per second. Can be changed between reads.
    clipped bool

    True if any conversion in the most recent read hit full scale (±fsr), so the input may be beyond the range. Use a larger fsr if it is.

    enable_ready_pin ¶

    enable_ready_pin() -> None

    Make the RDY pin pulse low each time a conversion finishes.

    RDY is J1 pin 5 (the chip's ALERT/RDY pin), pulled up to VDD on the board. Wire it to a GPIO and watch for the falling edge. Each board needs its own GPIO.

    resistance_from_voltage ¶

    resistance_from_voltage(
    v_adc: float,
    vdd: float = VDD_NOMINAL,
    r_excitation: float = R_EXCITATION,
) -> float

    Work out a bare resistive sensor's resistance on a channel with its RES jumper closed.

    The 10 kΩ excitation resistor and the sensor form a voltage divider:

    v_adc = vdd × Rs / (Rs + 10 kΩ), so Rs = 10 kΩ × v_adc / (vdd − v_adc)

    Parameters:

    Name Type Description Default
    v_adc float

    Voltage measured on the channel (V).

    		 required
    vdd float

    Board supply voltage (V). Use the measured value for best accuracy.

    		 VDD_NOMINAL
    r_excitation float

    Excitation resistor (Ω).

    		 R_EXCITATION

    Returns:

    Type Description
    float

    Sensor resistance (Ω): 0.0 for a short circuit and math.inf for an open circuit.
