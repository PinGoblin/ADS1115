    Raspberry Pi examples¶

    The scripts in the python/ folder. Each one imports the pingoblin_ads1115 package. Run them with python3 <script> inside the virtual environment where the package is installed; press Ctrl+C to stop.

    Script What it does Jumper setting
    01_read_all_channels.py Prints raw counts and volts for CH0–CH3 RES open
    02_thermistor_ntc.py 10 k NTC temperature with the Beta equation; can measure VDD live on a spare channel RES closed on the NTC channel
    03_light_and_pot.py Potentiometer as a percentage and a bare LDR as resistance and light level CH0 RES open, CH1 RES closed
    04_multiple_boards.py Finds boards at 0x48–0x4B and reads up to 16 channels One address jumper per board
    05_csv_logger.py Logs averaged readings to CSV, e.g. python3 05_csv_logger.py 60 log.csv Any
    06_calibrate.py One-point gain calibration, saved to calibration.json and applied by the other examples RES open on the channel being calibrated

    01_read_all_channels.py¶

    python/01_read_all_channels.py
    #!/usr/bin/env python3
"""Example 1: read all four channels.

Prints the raw count and voltage of CH0–CH3 twice a second. Press Ctrl+C to stop.

**Board setup**

- Host on J1.
- Voltage-output sensors on J2–J5 (GND, VDD, SIG).
- All RES jumpers open (the factory default).

Applies the calibration from `06_calibrate.py` if `calibration.json` exists.
"""
import time

from pingoblin_ads1115 import ADS1115, load_calibration, apply_calibration

adc = ADS1115(address=0x48, fsr=4.096)         # +/-4.096 V full scale, 128 samples/s
cal = load_calibration()                       # optional, see 06_calibrate.py

print("CH0 (J2)        CH1 (J3)        CH2 (J4)        CH3 (J5)")
try:
    while True:
        cells = []
        for ch in range(4):
            raw = adc.read_raw(ch)
            volts = apply_calibration(raw * adc.fsr / 32768, ch, cal)
            cells.append(f"{raw:6d} {volts:6.3f}V")
        print("  ".join(cells))
        time.sleep(0.5)
except KeyboardInterrupt:
    pass

    02_thermistor_ntc.py¶

    python/02_thermistor_ntc.py
    #!/usr/bin/env python3
"""Example 2: temperature from a 10 kΩ NTC thermistor.

**Board setup**

- Close the RES jumper of the channel you use (JP5 for CH0).
- Connect one thermistor lead to SIG (pin 3) and the other to GND (pin 1) of J2.
  The VDD pin is not used, and a thermistor has no polarity.

**Accuracy tips**

- Measure the board's real VDD between TP5 and TP6 and set `VDD`, or
- set `VDD_CHANNEL` to a spare channel and link that header's VDD pin to its SIG pin with
  a jumper wire (RES open). The script then measures VDD live.
- Set `R0`, `T0_C` and `BETA` from your thermistor's datasheet.
"""
import time

from pingoblin_ads1115 import (ADS1115, resistance_from_voltage, ntc_celsius,
                               load_calibration, apply_calibration)

NTC_CHANNEL = 0        # CH0 = J2, RES jumper JP5 closed
VDD = 3.30             # your measured supply voltage
VDD_CHANNEL = None     # e.g. 3 to measure VDD live on CH3 (J5 VDD linked to SIG)

# Thermistor datasheet values
R0 = 10_000.0          # resistance at T0
T0_C = 25.0
BETA = 3950.0          # check your part: 3380, 3435 and 3950 are all common

R_OPEN = 5_000_000     # above this the thermistor is treated as disconnected (a 10 k NTC is ~1 M at -55 C)

adc = ADS1115(fsr=4.096)
cal = load_calibration()

try:
    while True:
        vdd = VDD
        if VDD_CHANNEL is not None:
            vdd = apply_calibration(adc.read_voltage(VDD_CHANNEL, samples=8), VDD_CHANNEL, cal)
        v = apply_calibration(adc.read_voltage(NTC_CHANNEL, samples=16), NTC_CHANNEL, cal)
        if adc.clipped:
            print("Reading at full scale: on a 5 V board use ADS1115(fsr=6.144)")
        r = resistance_from_voltage(v, vdd)
        if r > R_OPEN:
            print("Open circuit - is the thermistor connected and RES closed?")
        elif r < 50:
            print("Short circuit - check the thermistor wiring")
        else:
            t = ntc_celsius(r, R0, T0_C, BETA)
            print(f"V={v:.4f} V  VDD={vdd:.3f} V  R={r/1000:7.3f} k  T={t:6.2f} C")
        time.sleep(1)
except KeyboardInterrupt:
    pass

    03_light_and_pot.py¶

    python/03_light_and_pot.py
    #!/usr/bin/env python3
"""Example 3: two sensor types on one board.

Shows how a voltage-output channel and a resistive channel are converted differently.

**Board setup**

| Channel | Sensor | RES jumper | Wiring |
|---|---|---|---|
| CH0 (J2) | Potentiometer | Open | Ends to GND and VDD, wiper to SIG |
| CH1 (J3) | Bare LDR | Closed (JP6) | One lead to SIG, the other to GND |
"""
import time

from pingoblin_ads1115 import ADS1115, resistance_from_voltage, percent_of_range

VDD = 3.30

adc = ADS1115(fsr=4.096)
POT, LDR = 0, 1        # channels

try:
    while True:
        v_pot = adc.read_voltage(POT, samples=8)
        pot_pct = percent_of_range(v_pot, 0.0, VDD)

        v_ldr = adc.read_voltage(LDR, samples=8)
        r_ldr = resistance_from_voltage(v_ldr, VDD)
        # LDR resistance falls as light rises; dark ~1 M, bright ~1 k.
        # Brightness is shown as % of the voltage swing (bright = low voltage).
        light_pct = 100.0 - percent_of_range(v_ldr, 0.0, VDD)

        r_txt = "open" if r_ldr == float("inf") else f"{r_ldr/1000:8.1f} k"
        print(f"Pot {pot_pct:5.1f} %   |   LDR {r_txt}  light {light_pct:5.1f} %")
        time.sleep(0.25)
except KeyboardInterrupt:
    pass

    04_multiple_boards.py¶

    python/04_multiple_boards.py
    #!/usr/bin/env python3
"""Example 4: several boards on one I²C bus, up to 16 channels.

Finds every board at 0x48–0x4B and prints all their channels once a second.

**Board setup**

Give every board a different address with the solder jumpers:

| Board | Jumpers | Address |
|---|---|---|
| A | JP1 closed (default) | 0x48 |
| B | Cut JP1, close JP2 | 0x49 |
| C | Cut JP1, close JP3 | 0x4A |
| D | Cut JP1, close JP4 | 0x4B |

Wire pins 1–4 of every board's J1 (VDD, GND, SCL, SDA) in parallel to the Pi.
`i2cdetect -y 1` lists the addresses the Pi can see. Up to four boards can share the Pi's bus.
"""
import time

from pingoblin_ads1115 import find_boards

boards = find_boards(fsr=4.096)          # tries 0x48-0x4B on I2C bus 1
for addr in boards:
    print(f"Found board at 0x{addr:02X}")

if not boards:
    raise SystemExit("No boards found - check wiring, power and `i2cdetect -y 1`.")

try:
    while True:
        line = []
        for addr, adc in boards.items():
            volts = " ".join(f"{adc.read_voltage(ch):5.3f}" for ch in range(4))
            line.append(f"0x{addr:02X}: {volts}")
        print("  |  ".join(line))
        time.sleep(1)
except KeyboardInterrupt:
    pass

    #!/usr/bin/env python3
"""Example 5: log all four channels to a CSV file.

Each row holds an ISO timestamp, then CH0–CH3 in volts (16-sample averages). Open the file
in a spreadsheet to chart it. Press Ctrl+C to stop.

**Usage**

```bash
python3 05_csv_logger.py                 # every 5 s to ads_log.csv
python3 05_csv_logger.py 60 garden.csv   # every 60 s to garden.csv
    """ import csv import os import sys import time from datetime import datetime

    from pingoblin_ads1115 import ADS1115, load_calibration, apply_calibration

    interval = float(sys.argv[1]) if len(sys.argv) > 1 else 5.0 path = sys.argv[2] if len(sys.argv) > 2 else "ads_log.csv"

    adc = ADS1115(fsr=4.096, rate=128) cal = load_calibration()

    new_file = not os.path.exists(path) with open(path, "a", newline="") as f: writer = csv.writer(f) if new_file: writer.writerow(["timestamp", "ch0_V", "ch1_V", "ch2_V", "ch3_V"]) print(f"Logging every {interval:g} s to {path} - Ctrl+C to stop") try: while True: start = time.monotonic() row = [datetime.now().isoformat(timespec="seconds")] for ch in range(4): row.append(f"{apply_calibration(adc.read_voltage(ch, samples=16), ch, cal):.5f}") writer.writerow(row) f.flush() print(", ".join(row)) time.sleep(max(0.0, interval - (time.monotonic() - start))) except KeyboardInterrupt: pass

    ## 06_calibrate.py

```python title="python/06_calibrate.py"
#!/usr/bin/env python3
"""Example 6: one-point gain calibration.

Removes the small gain error caused by the 4.7 kΩ series resistor and the ADC's own
tolerance (typically 0.1–0.2 %).

1. Leave the channel's RES jumper open.
2. Link the header's VDD pin to its SIG pin with a jumper wire, or apply any steady
   voltage between 1 V and VDD.
3. Measure that voltage at the header with a good multimeter.
4. Run `python3 06_calibrate.py <channel> <multimeter volts>`,
   for example `python3 06_calibrate.py 0 3.297`.

The factor is saved to `calibration.json` and applied automatically by the other
examples. Repeat for each channel you use.
"""
import sys

from pingoblin_ads1115 import ADS1115, load_calibration, save_calibration

if len(sys.argv) != 3:
    raise SystemExit(__doc__)

ch = int(sys.argv[1])
true_v = float(sys.argv[2])
if ch not in range(4) or not 0.5 <= true_v <= 5.5:
    raise SystemExit("Channel must be 0-3 and voltage 0.5-5.5 V")

adc = ADS1115(fsr=4.096, rate=8)           # slowest rate = lowest noise
measured = adc.read_voltage(ch, samples=32)
if measured < 0.25:
    raise SystemExit(f"CH{ch} reads {measured:.4f} V - is the voltage connected?")

factor = true_v / measured
if not 0.97 <= factor <= 1.03:
    raise SystemExit(f"Factor {factor:.5f} is outside +/-3 % - check the wiring and meter")

cal = load_calibration()
cal[str(ch)] = round(factor, 6)
save_calibration(cal)
print(f"CH{ch}: measured {measured:.5f} V, true {true_v:.5f} V -> factor {factor:.5f} saved")
